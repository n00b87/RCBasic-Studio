sub SetSpriteCanvasAntiAliasMode( c_num, aa_mode )

Sets the anti-alias mode for a sprite canvas

Possible modes

  • AA_MODE_OFF
  • AA_MODE_SIMPLE
  • AA_MODE_QUALITY
  • AA_MODE_LINE_SMOOTH
  • AA_MODE_POINT_SMOOTH
  • AA_MODE_FULL_BASIC
  • AA_MODE_ALPHA_TO_COVERAGE
